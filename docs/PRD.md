# PRD — ReCos (리코스)

화장품 원료 C2C 매칭 플랫폼. 벤치마크: cosrawmarket.com(원료장터/COOS).

---

## 1. 배경 & 문제

화장품 제조사·연구소·소규모 브랜드는 원료를 **대용량 최소포장 단위**로만 사야 해 비용 부담이
크고, 한편으로 **마감임박·잉여 원료**는 유통되지 못하고 폐기된다. 원본 cosrawmarket은 이를
판매자-구매자 직접 매칭으로 해결하지만, ① 검색·필터가 단순한 표 수준이고 ② 등록 정보가 빈약해
거래 판단이 어렵다.

**ReCos**는 동일한 매칭 모델과 친숙한 홈 구성을 유지하면서, **COOS 분류 기반 고급 검색·필터**와
**실물/패킹 사진·제조원·공급처·보관/개봉 상태 등 풍부한 등록 정보**로 "찾기"와 "판단하기"를
개선한다.

## 2. 목표 / 비목표

**목표**
- 마감임박·잉여·소량 원료가 빠르게 임자를 찾게 한다.
- 종류·기능·인증서 + 성분코드(INCI/CAS)·유효기한·서류 기준 정밀 검색.
- 문의 전에 거래 판단에 필요한 정보를 한눈에 노출.
- (추후) 멤버십으로 지속가능. v1은 구조만 선반영.

**비목표 (v1)**
- 사이트 내 결제·정산·에스크로
- 채팅·알림
- 배송/물류, 모바일 네이티브 앱
- 관리자 UI, 신고, 게시판, 구매희망(Want), 성분 사전, 임팩트 지표 (모두 추후)

## 3. 페르소나

- **판매자(P-Seller)**: 잉여/마감임박 원료를 보유한 제조사·유통사·연구소. "재고를 손해 덜 보고
  처분하고 싶다." → 등록이 쉽고, 신뢰가는 정보로 빠르게 연락받길 원함.
- **구매자(P-Buyer)**: 소량으로 특정 원료가 필요한 소규모 브랜드·연구자. "정확히 원하는 원료를
  조건에 맞게 찾고 싶다." → 정밀 검색과 충분한 정보, 빠른 연락처 확보를 원함.

## 4. 사용자 스토리 (v1)

판매자
- 로그인 후 원료를 등록한다(분류·수량·유효기한·실물/패킹 사진·서류·연락정보 포함).
- 내 등록물 상태를 가능→예약→완료로 바꾸고, 수정/삭제한다.

구매자
- 비로그인으로도 홈의 최근 등록 표와 검색 결과를 본다.
- 종류/기능/인증서/유효기한/서류/수량/가격/지역으로 필터링하고 임박순으로 정렬한다.
- 상세에서 사진·서류·전체 정보를 보고, **로그인하면 연락처를 열람**해 직접 연락한다.
- 관심 원료를 찜하고, 최근 본 원료를 다시 찾는다.

## 5. 기능 요구사항 (우선순위)

| ID | 기능 | 우선 |
|---|---|:---:|
| F1 | 이메일+구글 로그인, 프로필(이름·회사·연락처·지역) | P0 |
| F2 | 원료 등록 CRUD + 상태(가능/예약/완료) | P0 |
| F3 | 사진 업로드(한 칸·다중), MSDS/COA/SDS 서류 업로드(권장) | P0 |
| F4 | 홈: 원본 충실 구성 + 최근 등록 원료 표(9열) | P0 |
| F5 | 고급 검색·필터·정렬·페이지네이션 | P0 |
| F6 | 상세 페이지 + 연락처 로그인 게이팅 | P0 |
| F7 | 마이페이지(내 등록물·찜·최근 본·프로필) | P1 |
| F8 | 멤버십-Ready 권한 추상화(`permissions`·`featureGate`) | P1 |

상세 동작·검증 규칙은 `FEATURE_SPEC.md` 참조. 분류 목록은 `TAXONOMY.md`.

## 6. 성공 지표

- 등록 → 첫 연락처 열람까지 평균 시간
- 등록 대비 완료(매칭) 비율
- 검색 → 상세 → 연락처 열람 전환율
- WAU(주간 활성 사용자)

## 7. 범위 경계

- **v1**: F1~F8.
- **나중에**: 성분(INCI) 사전+연결, 게시판, 구매희망+매칭, 관리자/신고, 임팩트 지표,
  **멤버십 유료화 활성화**(게이팅 1순위: 연락처 열람).

## 8. 리스크 & 대응

- **신뢰/분쟁**: v1은 면책 고지 + 연락처 로그인 게이팅으로 최소화. (평판/인증은 추후 — 비전에서 제외 확정)
- **데이터 빈약 → 검색 무력화**: 필수 필드(분류·사진·서류·CAS)로 등록 품질 강제.
- **민감 서류 노출**: 서류는 비공개 버킷 + signed URL.
- **멤버십 도입 시 대규모 수정**: `permissions`/`featureGate` 단일 지점 추상화로 차단.
