# ROADMAP — ReCos

## v1 (현재 구현 대상)
화장품 원료 C2C 매칭의 핵심.
- 이메일+구글 로그인, 프로필
- 원료 등록 CRUD(분류·풍부한 정보·실물/패킹 사진·서류) + 상태(가능/예약/완료)
- 홈(원본 충실) + 최근 등록 원료 표(9열)
- 고급 검색·필터·정렬·페이지네이션
- 상세 + 연락처 로그인 게이팅
- 마이페이지(내 등록물·찜·최근 본·프로필)
- 멤버십-Ready 추상화(`permissions`·`featureGate`, `membership_tier` 컬럼)

**완료 기준**: `docs/`의 검증 시나리오(등록→검색→상세→연락처 열람→완료) 통과.

## v1.1 — 콘텐츠 & 양방향 매칭
- **성분(INCI) 사전** + 성분→해당 성분 보유 원료 연결 (헤더 "성분/원료" 탭 완성)
- **게시판**(원료 정보·질문 공유)
- **구매희망(Want)** 등록 + 판매자 노출

## v1.2 — 운영 도구
- **관리자 UI**(회원·등록물 관리, 숨김/삭제)
- **신고** 기능

## v2 — 수익화 (멤버십 활성화)
- 게이팅 1순위: **연락처 열람**(비회원/무료 → 제한, pro → 열람)
- 추가 후보: 고급 필터/정렬, 등록 개수, 노출 우선
- `subscriptions` 테이블 + 결제 연동
- 손볼 지점: `lib/permissions.ts` `view_contact` 분기, `lib/featureGate.ts`
  (DB `membership_tier`는 v1부터 존재 → 스키마 변경 최소)

## v2+ — 신뢰 & 임팩트 (후순위)
- 거래 임팩트 지표(회피 폐기량/비용)
- (평판/인증 배지는 현재 제품 비전에서 제외 — 필요 시 재검토)
