# ReCos 랜딩페이지(`/about`) 디자인 스펙

- **날짜:** 2026-06-12
- **브랜치:** feature/frontend-redesign
- **결과물:** 화장품 원료 잉여 재고 마켓플레이스 ReCos의 마케팅 인트로 랜딩페이지
- **구현 경로:** 본 스펙 → 프리뷰 HTML(정적, `preview/`) 승인 → Codex(dual-ai)가 Next.js/React로 구현

## 1. 배경과 목표

ReCos는 화장품 **원료(raw material)** 의 잉여 재고를 소량 필요처와 직접 연결하는 중개형 정보 플랫폼이다(배포: material-nine-zeta.vercel.app). 현재 홈(`/`)은 미니멀 히어로 + 최근 등록 원료만 노출한다.

이 스펙은 별도 마케팅 랜딩(`/about`)을 정의한다. 목적은 **재고를 보유한 기업(공급자)** 에게 "남는 원료를 방치하면 손해이며, ReCos로 회수 기회로 바꿀 수 있다"를 설득해 **재고 등록**(주 전환) 또는 **이메일 구독**(보조 전환)으로 이끄는 것.

### 카피 프레임워크 (출처: 랜딩 카피라이팅 강의 영상)

3단 설득 구조를 그대로 뼈대로 사용한다:

1. **멈추게 하기** — 타겟 호출 · 핵심 약속
2. **설득하기** — 고통 묘사 · 해결 후 변화 · 증거
3. **행동하게 하기** — 가치 스택 · 긴급성 · 보증 · CTA

> 원래 프레임워크의 "호기심 포인트"는 사용자 요청으로 **제외**.

### 서술 각도

- **공급자(재고 보유 기업) 중심**, 손실 회피 정공법. 구매자는 "해결 후 변화"·보조 CTA로 배치.
- 톤: 강한 마케팅형(대비·강조·정직한 긴급성).
- **초기 서비스이므로 후기·거래액·고객사 로고 등 실제 증거 자산이 없다 → 지어내지 않는다.** "증거"는 구조적 신뢰 요소(서류 검증·실물 확인·권한 제어)로 대체.

### 확정 사실 (카피에 사용 가능)

- 결제 중개 없음, **직접 연결** (코드 확인: `landing-preview.tsx`, `trade-notice.tsx`).
- **등록 무료 · 수수료 무료** (사용자 확인).
- 거래 책임 고지 = 기존 `TradeNotice` 문구 재사용.

## 2. 디자인 시스템

기존 토큰 그대로(`src/app/globals.css`). 새 색/폰트 도입 금지.

- 배경 `--bg #fff`, 표면 `--surface #f7f8f9`, 카드 `--card #fff`
- 잉크 `--ink #14171a`, 보조 `--sub #6b7280`, 라인 `--line #e8eaed`
- 시그널(러스트/강조) `--signal #c0492e` — 긴급성·강조에 절제 사용
- 라틴 폰트 `--font-lat`(Inter Tight), 본문 한글 sans
- 컨테이너 `max-w-[1180px] px-5 sm:px-8`, 라운드/클린, `ScrollReveal`로 섹션 등장

"강한 마케팅 톤"은 색을 늘리는 게 아니라 **타이포 대비(굵기·크기)·시그널 컬러 포인트·여백 리듬·대비 표(Before/After)** 로 만든다.

## 3. 페이지 구조 (섹션별 최종 카피)

라우트: `/about`. 상단 nav·하단 footer는 기존 레이아웃 재사용.

### ① HERO — 멈추게 하기

- eyebrow: `화장품 제조사 · 원료사 · OEM/ODM 담당자라면`
- H1: **안 쓰는 원료는, 가만히 둘수록 손해입니다.**
- sub: ReCos는 유효기한이 남은 원료를 필요한 곳과 직접 연결해, **폐기 비용을 회수 기회로** 바꿉니다.
- CTA: `[재고 원료 등록하기]`(주, `/listings/new`) · `[원료 검색하기]`(보조, `/listings`)
- 비주얼: 기존 `landing-preview.tsx` 인터랙티브 콘솔 목업(검색→판단→연락) 재활용
- (호기심 포인트 라인 없음)

### ② 고통 묘사 — 설득 1

헤더: **원료 재고, 쌓일수록 손해가 커지는 이유.**  *(4분할 카드)*

| 번호 | 제목 | 본문 |
|---|---|---|
| 01 | 폐기 비용 | 멀쩡한 원료를, 돈을 내고 버립니다. 폐기물 처리비는 덤. |
| 02 | 창고 점유 | 안 쓰는 원료가 보관 공간과 관리 인력을 잡아먹습니다. |
| 03 | 유효기한 | 매일 가치가 줄고, 기한이 지나면 0원이 됩니다. |
| 04 | 장부 손실 | 구매가는 비용으로 남고, 회수액은 0원. |

### ③ 해결 후 변화 — 설득 2 (Before → After)

헤더: **ReCos를 만나면, 이렇게 달라집니다.**

| 지금 | ReCos 이후 |
|---|---|
| 폐기 비용을 지출 | **회수 수익**이 발생 |
| 창고에 방치 | 필요한 곳으로 **이동** |
| 유효기한 카운트다운 | 기한 내 **거래 성사** |

작동 방식 3단계: **① 등록**(사진·CAS-NO·서류) → **② 연결**(소량 필요처와 매칭) → **③ 거래**(직접 연락·거래)

### ④ 증거 / 구조적 신뢰 — 설득 3

헤더: **처음 거래해도 안심할 수 있게.**

- **서류 검증** — MSDS·COA·CAS-NO·공급처를 거래 전에 확인
- **실물 확인** — 실제 사진과 보관 상태를 공개
- **권한 제어** — 연락처는 로그인·서버 권한으로 보호, 결제 중개 없이 직접 연결

### ⑤ 가치 스택 — 행동 1

헤더: **ReCos가 대신 해결하는 것들.**  (체크리스트)

- ✓ 폐기 업체를 따로 알아볼 필요 없음
- ✓ 소량 구매처를 찾아다닐 필요 없음
- ✓ 서류·사진으로 검증된 거래
- ✓ 결제 수수료 없는 직접 연결
- ✓ **등록은 무료, 몇 분이면 끝**

### ⑥ 긴급성 — 행동 2 (정직한 손실회피)

헤더: **기다릴수록, 받을 수 있는 값은 줄어듭니다.**
본문: 유효기한은 매일 줄어들고, 기한이 가까운 원료일수록 거래는 어려워집니다. 지금 등록한 원료가 **초기 등록 원료로 먼저 노출**됩니다.
*(가짜 "N명 한정" 대신 유효기한 자체를 정직한 긴급성으로. 시그널 컬러 포인트.)*

### ⑦ 보증 + 최종 CTA — 행동 3·4

- 보증: 등록은 무료입니다. 거래가 성사돼야 의미가 있고, **등록 자체는 부담이 없습니다.**
- 기존 `TradeNotice`(거래 책임 고지) 배치
- 최종 CTA 헤더: **창고에 잠든 원료부터, 지금 등록하세요.** → `[재고 원료 등록하기]` · `[원료 검색하기]`

### ⑧ 이메일 수집 밴드

최종 CTA 다음, footer 직전. 지금 등록할 원료가 없는 방문자를 위한 보조 전환.

- 헤더: **지금 등록할 원료가 없어도 괜찮습니다.**
- sub: 새 원료와 ReCos 소식을 이메일로 보내드립니다.
- 입력: `[이메일 주소]` + `[소식 받기]` 버튼
- 상태: 제출 성공/중복/에러 인라인 메시지
- 저장: Supabase 구독 테이블(예: `subscribers`, 컬럼 `email`, `created_at`, unique email). **구체 구현은 Codex가 결정**; 본 스펙은 UI·동작 계약만 정의.

## 4. 컴포넌트 경계 (구현 가이드)

`/about` 페이지는 섹션 단위 컴포넌트로 분리한다. 각 컴포넌트는 자기 카피·레이아웃만 책임지고, 페이지가 순서대로 조립한다.

- `AboutHero` — 콘솔 목업(`LandingPreview`) 포함
- `ProblemGrid` — 4분할 고통 카드
- `BeforeAfter` — 대비 표 + 3단계
- `TrustPillars` — 구조적 신뢰 3요소
- `ValueStack` — 체크리스트
- `UrgencyBand` — 긴급성(시그널)
- `FinalCta` — 보증 + TradeNotice + 버튼
- `EmailCapture` — 클라이언트 컴포넌트(폼 상태·제출), 서버 액션/route handler로 저장

기존 자산 재사용: `ScrollReveal`, `SectionHead`, `TradeNotice`, `LandingPreview`.

## 5. 비목표 (YAGNI)

- 현재 홈(`/`) 변경 없음 (별도 라우트만 추가).
- 다국어/영문 버전 없음 (한국어 단일).
- A/B 테스트, 애널리틱스 이벤트 설계는 범위 외.
- 가짜 후기·거래액·로고 일절 없음.

## 6. 성공 기준

- `/about` 접속 시 7개 섹션 + 이메일 밴드가 기존 디자인 토큰으로 렌더.
- 주 CTA가 `/listings/new`, 보조가 `/listings`로 연결.
- 이메일 폼: 유효 이메일 제출 시 저장 + 성공 메시지, 잘못된 입력·중복 시 인라인 에러.
- 카피에 미검증 수치·후기 없음.
- 모바일(단일 컬럼)·데스크톱 반응형.
