# ReCos 홈페이지 정직성 패스 & 핵심 플로우 검증 (Design)

- 날짜: 2026-06-12
- 브랜치: `feature/frontend-redesign`
- 진행 방식: dual-ai (Codex 구현 → Claude 검토 → 미달 시 재지시), 종료 조건 전부 통과까지 반복. git 커밋은 Claude가 직접.

## 목표 (Goal)

홈페이지와 핵심 거래 플로우를 "정직하고, 작동하고, 일관된" 상태로 만든다.
가짜 정보를 제거하고, 로그인·회원가입·등록·조회가 실제로 동작하며, 개인정보 노출 정책을
정리한다. 아래 종료 조건(E2E 포함)이 전부 통과될 때까지 dual-ai 루프를 돌린다.

## 변경 범위

### 1. 로그인 (실시간 진단 후 수정)
앱을 실제로 실행해 로그인 실패의 진짜 원인을 진단한 뒤 수정한다.
코드상 Supabase 인증 연결([login/actions.ts](../../../src/app/login/actions.ts))과
헤더 버튼([site-header.tsx](../../../src/components/site-header.tsx))은 이미 연결되어 있으므로,
원인 후보는: Supabase Auth 사용자/이메일 확인 정책, Google OAuth provider 미활성화,
환경 설정 등. 진단 결과에 따라 코드 또는 Supabase 설정을 고친다.
- 검증: 실제 계정으로 로그인 → 헤더가 로그아웃 상태로 전환 → `/mypage` 접근 가능.

### 2. 최근 등록 원료 (데모 명시 + 이미지 전부 제거)
[page.tsx](../../../src/app/page.tsx) 기준:
- 모든 placeholder 이미지 제거: `MaterialImage`(230px featured 이미지 + 46px 썸네일) 전부 삭제.
- 샘플 데이터는 유지하되 섹션에 **"예시 데이터" 라벨/배지**를 명시.
- 이미지 제거로 비는 레이아웃을 텍스트 중심(원료명·CAS·공급처·가격·스펙)으로 재구성.

### 3. 통계 밴드 완전 제거
[page.tsx](../../../src/app/page.tsx) 의 18종/21개/10일 블록 삭제.
사용처가 없어지는 [stat-band.tsx](../../../src/components/stat-band.tsx)는 다른 사용처가 없으면 정리(확인 후).

### 4. 히어로 카피 (문제 제기·공감 중심) — 채택안 B
- H1: **"유효기한이 남은 원료를, 그냥 버리고 계신가요?"**
- Sub: **"소량이 필요한 곳과 직접 연결해, 낭비와 비용을 동시에 줄입니다."**
- 기존 eyebrow / CTA(원료 검색하기 · 원료 등록하기) 구조는 유지.

### 5. 회원가입 → 품목 등록 플로우 검증
회원가입이 실제로 동작하고, 가입한 유저가 품목을 등록할 수 있어야 한다(실브라우저 검증).

### 6. 등록물의 타 유저 노출 검증
A 유저가 등록한 원료를 B 유저(또는 비로그인)가 `/listings` 목록과 상세 페이지에서
확인할 수 있어야 한다.

### 7. 개인정보 노출 정책 — 회사 정보는 입력 유지, 노출만 숨김
- 회원가입/프로필의 **회사 입력 항목은 그대로 유지**(데이터는 계속 수집).
- [contact-gate.tsx](../../../src/components/contact-gate.tsx) 의 연락처 카드에서
  **회사명(company_name) 행만 제거** → 담당자(이름) · 전화 · 이메일만 노출.
- **사진(photos) + 명세서(MSDS/COA/SDS docs) 업로드는 그대로 유지** — 모두 업로드 가능.

## 제약 (Constraints)
- 프레젠테이션/정책 레이어 중심. 쿼리·권한·검증·api·supabase 로직은 필요한 최소한만 수정.
- 디자인은 토큰 기반 유지: 색/폰트 하드코딩 금지, 기존 토큰(`bg-bg`, `text-ink`, `bg-accent` 등) 사용.
- 요청 범위 밖 리팩터링 금지(surgical changes).

## 종료 조건 = Definition of Done (전부 통과 시 루프 정지)
1. 가짜 통계(18/21/10) 제거, 데모 라벨 명시, 최근 등록 원료 영역 이미지 전부 제거.
2. 히어로 카피 B 적용.
3. 로그인 실제 작동: 계정 로그인 → 헤더 상태 전환 → `/mypage` 진입.
4. ContactGate에서 회사명 미노출(이름+전화+이메일만), 회사 입력은 유지.
5. 디자인 토큰 일관성(하드코딩 색/폰트 없음).
6. `npm run build` + `npm run lint` 통과, 타입 에러 0.
7. 모바일 반응형 깨짐 없음.
8. **E2E 단일 시나리오 실브라우저 통과**:
   회원가입 → 로그인 → 품목 등록(사진+서류 업로드) → 다른 유저로 전환 →
   목록·상세에서 해당 원료 확인 → 연락처 카드에 이름+연락처만(회사 없음) 표시.
