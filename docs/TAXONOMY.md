# TAXONOMY — COOS 분류 체계 (고정 목록)

원본 cosrawmarket(COOS)의 필터 분류를 **그대로** 채택한다. 이 목록은 코드 상수
`lib/taxonomy.ts`의 단일 출처(single source of truth)이며, 등록 폼·검색 필터·표시는 모두
이 상수를 참조한다. 값은 한국어 라벨을 그대로 저장한다(별도 코드 매핑 없이 라벨 = 값).

> 참고: 등록물의 **종류(type)는 택1**, **기능(function)은 다중 선택**, **인증서(cert)는 다중 선택**.

```

```

> ⚠️ 열린 항목: 원본 캡처 하단이 잘려 인증서 전체 목록 미확정. 위 3종으로 시작하고,
> 추후 확인되는 항목(예: ECOCERT, ISO, HALAL, VEGAN 등)을 `CERTS` 상수에 추가한다.
> 인증서는 자유 추가 가능성이 있으므로 코드 상수만 늘리면 되도록 설계한다.

## 코드 상수 형태 (구현 가이드)

```ts
// lib/taxonomy.ts
export const TYPES = [
  "추출물", "보습제", "점증제/점도제", "경도제/버터/왁스", "오일/에몰리언트",
  "자외선차단제", "유화제", "가용화제", "계면활성제", "방부제/보존제", "스크럽",
  "파우더/색소/염료/안료", "첨가제/액티브", "금속이온봉쇄제", "단백질/펩타이드",
  "항산화제", "향료", "기타",
] as const;

export const FUNCTIONS = [
  "보습", "미백/화이트닝", "컨디셔닝", "피부 영양 공급", "자극 완화/진정", "탄력 강화",
  "항노화/주름 개선", "모공 축소", "피지 조절", "각질 제거", "자외선 차단", "항산화",
  "피부 장벽 강화", "여드름/트러블 케어", "항균/항염", "제형 안정화", "사용감 개선",
  "보존/항균", "금속 이온 봉쇄/안정화", "피부 재생", "탈취/소취/향",
] as const;

export const CERTS = ["USDA", "COSMOS", "REACH"] as const;

export type MaterialType = typeof TYPES[number];
export type MaterialFunction = typeof FUNCTIONS[number];
export type Cert = typeof CERTS[number];
```

DB 저장: `type_category text`(TYPES 중 하나), `function_tags text[]`, `cert_tags text[]`.
검색 필터는 종류=동등 비교, 기능/인증서=배열 포함(`&&` 또는 `@>`, GIN 인덱스).
